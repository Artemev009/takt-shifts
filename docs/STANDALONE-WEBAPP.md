# «Такт»: самостоятельное веб-приложение без ChatGPT

Это инструкция публикации **существующей серверной версии**, а не GitHub Pages.
Код кабинетов, защищённые серверные сессии, график сотрудников и общая база работают
в одном Cloudflare Worker с D1. Мобильные устройства открывают один адрес
`https://<имя-worker>.<ваш-subdomain>.workers.dev/`. После установки PWA отображается
отдельная иконка на домашнем экране.

## Разовая настройка

1. Откройте [Cloudflare Dashboard](https://dash.cloudflare.com/) с аккаунтом компании.
   В **Workers & Pages → D1** создайте базу **`takt-shifts-live`**.
   Сохраните её UUID `database_id` и Account ID. Не используйте базу ChatGPT Sites
   как альтернативу: это самостоятельная БД.
2. Создайте Cloudflare API Token с правами **Workers Scripts: Edit**, **D1: Edit**
   только в целевом аккаунте. Не сообщайте токен через чат и не сохраняйте в Git.
3. В GitHub-репозитории `Artemev009/takt-shifts` откройте
   **Settings → Secrets and variables → Actions → Repository secrets**.
   Добавьте:
   - `CLOUDFLARE_API_TOKEN` — облачный API token;
   - `CLOUDFLARE_ACCOUNT_ID` — 32 символа Account ID;
   - `CLOUDFLARE_D1_DATABASE_ID` — UUID созданной D1;
   - `TAKT_MANAGER_USERNAME` — логин руководителя (латинские буквы, цифры, точки);
   - `TAKT_MANAGER_PASSWORD` — временный пароль, от 12 символов;
   - `TAKT_MANAGER_NAME` — имя руководителя.
   При нестандартном названии базы добавьте `CLOUDFLARE_D1_DATABASE_NAME` с её названием.
4. В **Actions → Deploy standalone Takt web app → Run workflow** включите
   `bootstrap_manager=true` **только при первом развёртывании**, затем запустите.
   Workflow проверяет код, применяет SQL-миграции к явно указанной D1,
   создаёт первый парольный аккаунт и публикует Worker.
5. Откройте HTTPS-адрес Worker, указанный в конце журнала шага
   **Publish independent HTTPS web app**. Проверьте `/healthz`:
   `{"ready":true}` с HTTP 200. Войдите по логину руководителя,
   смените временный пароль, зайдите в «Команда и доступ» и создайте
   первого сотрудника.
6. Повторно выполняйте тот же workflow с `bootstrap_manager=false`.
   Секрет `TAKT_MANAGER_PASSWORD` после первоначального запуска
   удалите из GitHub Actions Secrets; первичный пароль уже будет изменён.
   Его потеря при отсутствии других руководителей потребует отдельной
   процедуры восстановления через защищённое административное подключение к D1.

## Автоматическая проверка опубликованного адреса

После шага `wrangler deploy` GitHub Actions теперь **проверяет настоящий URL**: доступность `/healthz`, готовность D1 и руководителя, страницу самостоятельного входа по паролю, PWA-manifest и отказ API анонимному пользователю. При неуспехе запуск **помечается ошибкой**, даже если загрузка кода прошла успешно. После успеха ссылка появляется в **GitHub Actions → Summary** (раздел «Такт — публичное веб-приложение»). Поскольку DNS после первой публикации может обновляться не сразу, проверка повторяется до шести раз.

## Важно для безопасности

- **Никаких ChatGPT-аккаунтов не требуется**, режим доверия к внешним
  `oai-authenticated-*` заголовкам на отдельном Worker принудительно отключён.
- Config содержит **явный database_id**: приложение не создаёт
  новую пустую D1 при повторных деплоях. Не подставляйте случайные ID.
- GitHub Pages — только демонстрация с данными в браузере. Заявки и смены
  сотрудников работают на отдельном Worker и общей базе.
- Публикация через GitHub Actions выполняется **только вручную**.
  Изменение исходного кода не начинает незапрошенный деплой на рабочий сервер.
- Перед подключением реальных работников согласуйте права доступа,
  политику персональных данных и резервное копирование D1.
- Код `/healthz` проверяет миграции и наличие активного руководителя с паролем;
  он **не гарантирует**, что вход проверен на реальных устройствах.
- Для пилота проверьте на двух независимых устройствах: менеджер создаёт
  аккаунт сотрудника → сотрудник меняет пароль → отправляет заявку →
  менеджер одобряет → общий график обновляется → приход/уход с кодом →
  CSV и история часов. Затем проверьте блокировку отключённого аккаунта.

## Обновления и диагностика

Запускайте **Deploy standalone Takt web app** с `bootstrap_manager=false`.
Скрипт `scripts/prepare-wrangler.mjs` создаёт временную Wrangler-конфигурацию
из GitHub Secrets. `wrangler.json` и bootstrap SQL исключены из Git,
реальные пароли в репозитории не хранятся.

Если `/healthz` отвечает 503, проверьте привязку D1,
результаты миграций и создание менеджера в журнале Actions.
Если 200, но логин не открывается с чужого устройства, проверьте,
что используется адрес **workers.dev**, а не адрес ChatGPT Sites.
